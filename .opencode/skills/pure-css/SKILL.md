# CSS Puro

## Regla
No usar ninguna libreria de estilos (ni Tailwind, ni Bootstrap, ni Material UI).

## Organizacion
- Archivos CSS en `src/styles/`.
- Nombres de clase descriptivos (task-form, task-list).
- Variables CSS para colores y tamanios al inicio.

## Buenas practicas
- Flexbox o grid para layouts.
- Max-width y margin auto para centrar.
- Media queries para responsive.
- Transiciones suaves en hover y click.
