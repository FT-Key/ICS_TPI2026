# React Router

## Cuando usarlo
Cuando el proyecto tiene multiples paginas.

## Como usarlo
- BrowserRouter y Routes en App.tsx.
- Componentes NavLink para navegar.
- useParams() para parametros de URL.
- useNavigate() para redireccionar.

## Estructura
- Paginas en `src/pages/`.
- Layout comun con barra de navegacion.
